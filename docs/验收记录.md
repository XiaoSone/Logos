## 环境与限制

- Flutter 3.47.7 / Dart 3.13.5；Corretto Java 21；Android SDK 36，minSdk 26。
- 目标数据库为 PG16；本机 Docker 未启动，实际测试 PG18，仍需在 PG16＋Redis7 环境复验。
- 原 App 的 ARM 原生库未能在 x86_64 模拟器正常初始化。Logos 仍需 ARM 真机测试、不同屏幕与大字体检查、长时阅读性能检查。
- Web 是辅助预览。其 IndexedDB 和浏览器安全存储不等同于 Android 私有 SQLite / Keystore。
- 主密钥在本地服务文件中，不在 APK；首次联网解锁后，用户可主动下载设备密钥加密的离线缓存。单元测试不替代完整断网冷启动测试。
- 开发登录不提供生产短信或客户端云同步。每日经文当前为 31 条轮转；阅读计划、TTS、图片分享卡片、AI 与图谱按阶段继续。
- 生产短信、游客合并、Redis 限流/撤销、正式签名、证书固定、隐私注销和备份策略仍需完成，当前版本不得作为生产版发布。

## 可重复命令

从根目录按 README 配置本地环境后，依次运行：

```powershell
.tools/venv/Scripts/python.exe tools/verify_data.py
mvn -f backend/pom.xml test
cd apps/logos
flutter analyze --no-pub
flutter test --no-pub --concurrency=1
flutter build apk --debug --target-platform android-arm64,android-x64 --no-pub
flutter build web --no-wasm-dry-run --no-pub
```

本机内存与 C 盘空间紧张时，构建、模拟器、分析器应串行运行。Android 已关闭 Kotlin 增量编译，避免 C 盘 Pub 缓存与 D 盘项目之间的缓存相对路径错误。
