# Git 基线与独立备份

## 基线范围

Git 纳入 Flutter/后端源码、测试、SQL、开发工具、架构与验收文档、公共领域经文数据及其密文快照。`.tools`、SDK/JDK、构建缓存、运行日志、数据库、APK、keystore、JWT/Bible 主密钥和设备个人数据不纳入 Git。`analysis` 仅纳入人工研究说明与目录说明。

开发 JWT 密钥保存在 `.tools/jwt-secret.txt`，`tools/dev.ps1 backend/check` 在未设置 `JWT_SECRET` 时从该文件加载；首次缺失则安全随机生成。`application-dev.yml` 只引用环境变量。使用原生 Maven 时需自行设置 `JWT_SECRET`，不要把密钥写入命令行或提交文件。

当前应用构建号为 2，“关于 Logos”显示构建号。正常 APK 与独立验收 APK 分别构建，验收 APK 不覆盖 `dist` 中的正常安装包。

## 创建备份

先提交全部应纳入基线的源码，再运行（目标目录必须不存在且位于工作区之外）：

```powershell
cd D:\Project\pre\Logos
.tools/venv/Scripts/python.exe tools/backup_project.py --output D:\Project\backups\Logos\选定备份目录
```

脚本要求工作区没有未提交的源码变化，项目 PG18/55432 在线。`--pg-bin` 可指定 PostgreSQL 工具目录。

备份包含：

- `source.zip`：所提交版本的源码快照；`history.bundle`：独立 Git 历史。
- `artifacts/`：当前 `dist` 的正常 APK 及已保留旧包，逐个验证 SHA256。
- `private.aes256gcm`：加密保存的 `logos` 数据库一致性转储、匹配经文主密钥、开发 JWT 密钥、可选 `.env`/开发签名 key，以及已有 `.tools/device-backups`。不会读取当前手机或复制整个 SDK/PG 数据目录。
- `private-key.dpapi`：由当前 Windows 用户 DPAPI 保护的随机 AES 密钥。密钥不进入 Git、不打印。
- `manifest.json`、`SHA256SUMS.json`、`RESTORE.txt`：提交号、校验和、实际恢复验证与恢复说明。

脚本实际解压检查源码、从 bundle 克隆核对提交、解密私有归档、比较本地密钥，并把解密得到的数据库转储恢复到独立 `logos_restore_<随机编号>` 库，核对 66 卷/31,092 节地址后删除临时库。清理包含私有明文的临时目录成功后，才写入完成 manifest 与校验清单；Windows Git 只读对象会先解除只读再清理。任何步骤失败均不能视为完成备份；成功目录应同时存在 manifest、校验清单和恢复说明。

## 恢复

源码可直接 `git clone history.bundle 新目录`，不依赖当前工作区。校验私有备份后，在同一 Windows 用户/机器上恢复到新的私有目录：

```powershell
.tools/venv/Scripts/python.exe tools/backup_project.py --extract-private 备份目录 --to 新私有目录
```

该命令只解密到指定新目录，不覆盖工作区、不恢复到现有数据库。按 `RESTORE.txt` 将转储恢复到新库，核对后再配置服务；运行密钥只放回被忽略的 `.tools` 路径。私有解密产物包含个人数据及密钥，不得提交。

DPAPI 保护的私有备份依赖当前 Windows 用户/机器，不能承诺换机后可解密；源码、Git 历史和 APK 不受此限制。独立目录提供工作区之外的副本，但同一磁盘不构成异地灾备，应另行保存到其他介质；若需要换机恢复私有密钥，需另行安排可移植的安全密钥保管。

既有手机文件备份不等于 Android Keystore 的可迁移备份。不要把旧版 APK 直接覆盖到已升级的 v2 数据库，也不要用卸载/清数据代替迁移验收。
